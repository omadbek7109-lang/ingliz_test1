# WebQuiz — Veb dasturlash testlari

Veb asoslari, HTML5, CSS3, JavaScript va jQuery bo‘yicha 325 ta savol, har biri 10 ta savoldan iborat testlarga bo‘lingan.

- Har bir savolda 4 ta variant (har safar aralashtiriladi)
- To‘g‘ri javob: yashil yonadi, “To‘g‘ri!” va avtomatik keyingi savolga o‘tadi
- Noto‘g‘ri javob: qizil bo‘ladi va to‘g‘ri javob ko‘rsatiladi
- Natija sahifasi, xatolar tahlili, “Xatolarim” va “Aralash test” rejimlari
- Eng yaxshi natijalar brauzerda saqlanadi
- Klaviatura: `1–4` / `A–D` — tanlash, `Enter` — keyingi

Fayllar: `index.html`, `style.css`, `app.js`, `questions.js` (savollar va javob kaliti).
